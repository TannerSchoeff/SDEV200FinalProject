# SDEV200FinalProject
A budgeting app made with java, and using a jsp interface, Takes a users income and divides it into three categories to help with budgeting.

INSTRUCTIONS:
1. Download and open the project in your desired IDE
2. Locate BudgetingAppApplication.java and run the file
3. Open your browser and enter https://localhost:8080 into the URL bar
4. The program should be running, enter in a username and your monthly income, and it will calculate a budget, you can enter the same username into the right box to check the budget you made.
